# Сбор презентаций

Веб-приложение для сбора презентаций участников мероприятия (конференции, защиты проектов и т. п.).

**Стек:** FastAPI · SQLite + SQLAlchemy + Alembic · React + Vite · Tailwind CSS · Caddy · Docker Compose

## Возможности

**Участник**
- Регистрация по почте и паролю + код от организаторов (защита от посторонних).
- Профиль: ФИО, класс (цифра и буква), секция — можно менять в любой момент.
- Загрузка презентации PowerPoint (`.pptx`) с прогрессом; замена и удаление до дедлайна.
- Дедлайн с обратным отсчётом в личном кабинете.

**Организатор секции**
- Список участников своей секции в порядке выступлений.
- Скачивание презентации каждого участника.
- ZIP со всеми презентациями: `01. Фамилия Имя Отчество (9А).pptx`, …
- Скачивание объединённой презентации, если суперюзер её собрал.

**Суперюзер**
- Видит все секции и всех участников, меняет любые данные (включая секцию, почту, пароль), загружает/удаляет файлы за участника (в том числе после дедлайна).
- Создаёт секции, меняет их порядок, создаёт организаторов (по одному или несколько на секцию) и других суперюзеров.
- Задаёт порядок выступлений (drag-and-drop, на телефоне — стрелками).
- Ставит дедлайн, код регистрации, открывает/закрывает регистрацию.
- Брендинг: заголовок, название мероприятия, описание, подвал, основной цвет, логотип.
- Собирает **объединённую презентацию** секции: титульный слайд секции, затем для каждого участника — разделительный слайд в цветах сайта («Следующий участник», ФИО, класс, номер) и его слайды. Оформление исходных презентаций (мастера, макеты, темы, картинки, видео) сохраняется. Если после сборки изменились файлы, порядок или данные участников, интерфейс подскажет пересобрать.

Адаптивный интерфейс (телефон/планшет/десктоп), светлая/тёмная тема (или как в системе).

## Запуск

```bash
cp .env.example .env
# обязательно поменяйте SECRET_KEY и ADMIN_PASSWORD
docker compose up -d --build
```

Сайт откроется на `http://<сервер>/`. Вход для организаторов — маленькая ссылка внизу главной страницы,
первый суперюзер — `ADMIN_LOGIN` / `ADMIN_PASSWORD` из `.env`.

Для HTTPS укажите домен в `SITE_ADDRESS` (например, `SITE_ADDRESS=talks.school.ru`) — Caddy сам получит сертификат
Let's Encrypt (порты 80 и 443 должны быть доступны извне).

### Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SITE_ADDRESS` | `:80` | Адрес для Caddy: `:80` или домен |
| `SECRET_KEY` | — | Секрет для подписи токенов |
| `ADMIN_LOGIN` / `ADMIN_PASSWORD` | `admin` / `admin` | Первый суперюзер (создаётся, если суперюзеров нет) |
| `REGISTRATION_CODE` | `letmein` | Начальный код регистрации (дальше меняется в настройках) |
| `MAX_UPLOAD_MB` | `300` | Максимальный размер презентации |
| `TOKEN_TTL_HOURS` | `72` | Время жизни сессии |

### Данные

Всё хранится в docker-томе `app_data` (`/data` внутри контейнера backend):

```
/data/app.db        — база SQLite
/data/uploads/<id>/ — презентации участников
/data/merged/       — объединённые презентации
/data/branding/     — логотип
```

Резервная копия: `docker compose cp backend:/data ./backup`.

Миграции Alembic применяются автоматически при старте контейнера backend.

## Разработка

```bash
# backend
cd backend
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
export DATA_DIR=./data
alembic upgrade head
uvicorn app.main:app --reload       # http://localhost:8000/api/docs
pytest

# frontend (проксирует /api на :8000)
cd frontend
npm install
npm run dev                          # http://localhost:5173
```

## Ограничения объединённой презентации

- Поддерживается только `.pptx` (старый `.ppt` нужно пересохранить в PowerPoint).
- Заметки докладчика и комментарии в объединённый файл не переносятся.
- В одном `.pptx` может быть только один размер слайда: берётся самый частый среди участников (обычно 16:9).
  Если у кого-то другой формат (например, 4:3), при сборке будет показано предупреждение.
- Встроенные в исходные презентации шрифты не переносятся.
